
# Contribuições dos Participantes

Bem-vindo ao Guia Colaborativo de Git e GitHub!

Esta pasta receberá as contribuições realizadas durante o workshop TecnoMonte 2026.

## Como participar?

Cada participante deve:

1. Criar uma issue no repositório original.
2. Fazer um fork do repositório.
3. Clonar seu fork pelo GitHub Desktop.
4. Criar uma branch.
5. Adicionar seu próprio arquivo Markdown nesta pasta.
6. Realizar um commit e publicar a branch.
7. Abrir um pull request para o repositório original.
8. Revisar a contribuição de um colega.
9. Responder ao feedback recebido.

## Nome do arquivo

Utilize o formato:

seuusuario-issue-N.md

Substitua:
- seuusuario pelo seu nome de usuário no GitHub.
- N pelo número da issue criada.

Exemplo:

gabriel123-issue-15.md

## O que escrever?

Escolha um comando ou conceito do Git e explique:

- O que é?
- Como utilizar?
- Um exemplo prático.
- Uma dica para iniciantes.

## Regras

- Cada participante cria seu próprio arquivo.
- Não modifique arquivos de outros participantes.
- Utilize mensagens de commit claras.
- Relacione o pull request à sua issue.
- Responda aos comentários recebidos.
- Aguarde a revisão e integração dos organizadores.
