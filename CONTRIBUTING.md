
# Guia de Contribuição - TecnoMonte 2026

Bem-vindo ao workshop de colaboração com Git e GitHub!

Neste guia, você aprenderá a contribuir para um projeto utilizando GitHub Desktop e o navegador.

## 1. Criar uma Issue

No repositório original:

1. Acesse a aba Issues.
2. Clique em New issue.
3. Crie um título claro para sua contribuição.
4. Descreva o conceito ou comando Git escolhido.
5. Adicione os critérios de aceitação.
6. Publique a issue e anote seu número.

Exemplo de critérios:

- [ ] Criar meu arquivo Markdown.
- [ ] Explicar um comando ou conceito Git.
- [ ] Apresentar um exemplo de utilização.
- [ ] Adicionar uma dica para iniciantes.

## 2. Fazer um Fork

1. Acesse o repositório original.
2. Clique em Fork.
3. Selecione sua conta.
4. Clique em Create fork.

O fork será uma cópia do projeto na sua conta.

## 3. Clonar pelo GitHub Desktop

1. Abra o GitHub Desktop.
2. Clique em File > Clone repository.
3. Selecione seu fork na aba GitHub.com.
4. Escolha uma pasta no computador.
5. Clique em Clone.

Se o GitHub Desktop perguntar como você pretende usar o fork, escolha a opção de contribuir para o projeto original.

## 4. Criar uma Branch

No GitHub Desktop:

1. Clique em Current Branch.
2. Selecione New Branch.
3. Digite um nome como:

contribuicao-seuusuario

4. Clique em Create Branch.

## 5. Criar sua Contribuição

Abra a pasta do projeto no seu editor.

Dentro de contribuicoes/, crie um arquivo com o nome:

seuusuario-issue-N.md

Substitua N pelo número da sua issue.

Exemplo:

gabriel123-issue-25.md

Seu arquivo deve conter:

- Título do comando ou conceito.
- Seu usuário do GitHub.
- Explicação do conceito.
- Exemplo de utilização.
- Dica para iniciantes.

Salve o arquivo.

## 6. Fazer o Commit

No GitHub Desktop:

1. Abra a aba Changes.
2. Confira o arquivo modificado.
3. Escreva uma mensagem clara.

Exemplo:

Adiciona explicacao sobre git status

4. Clique em Commit to sua-branch.

## 7. Publicar a Branch

Clique em Publish branch no GitHub Desktop.

Sua alteração será enviada para seu fork no GitHub.

## 8. Abrir um Pull Request

1. Clique em Create Pull Request.
2. Confira o destino:

Repositorio original: workshop-github-tecnomonte-2026
Branch de destino: main

3. Crie um título descritivo.
4. Explique o que foi adicionado.
5. Relacione a issue escrevendo:

Closes #N

Substitua N pelo número da sua issue.

6. Clique em Create pull request.

## 9. Revisão em Duplas

Troque o link do pull request com um colega.

O revisor deverá:

1. Abrir o pull request.
2. Conferir a aba Files changed.
3. Comparar com os critérios da issue.
4. Registrar um comentário útil.
5. Enviar a revisão como Comment.

O autor deverá:

1. Ler o comentário recebido.
2. Responder ao colega.
3. Corrigir o arquivo, caso necessário.
4. Fazer novo commit na mesma branch.
5. Publicar a atualização.

O pull request será atualizado automaticamente.

## 10. Integração

Os organizadores verificarão as contribuições.

Depois da conferência, os pull requests aprovados poderão ser integrados à branch main.

## Regras Importantes

- Cada participante cria seu próprio arquivo.
- Não edite arquivos dos colegas.
- Não modifique diretamente a branch main.
- Sempre utilize uma branch para contribuir.
- Mantenha as mensagens de commit claras.
- Respeite os comentários dos revisores.
- Aguarde a integração pelos organizadores.

## Parabéns!

Ao concluir essas etapas, você terá participado de um fluxo real de colaboração em um projeto GitHub.
